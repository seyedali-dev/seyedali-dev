### 🧠 About Me

- 💼 **Currently:** Go backend engineer, building scalable systems that don't fall over.
- 🦀 **Obsessed with:** Rust — systems programming, CLI tools, and anything that benefits from memory safety and speed.
- ☕ **Origin story:** 3+ years of Java/Spring Boot microservices. That's where I learned the value of clean architecture
  and reliability.
- ⚙️ **Core philosophy:** Simplicity, concurrency, and performance are not trade-offs — they're design goals.
- 🔧 **What I build:** Developer tooling. Infrastructure libraries. CLI utilities. Things that solve real problems.
- ⏰ **Routine:** 4 AM — 7 AM is personal project time. Every day. No exceptions. Ok, maybe somedays are exceptions...
- 🧘 **Coding is:** craftsmanship. I care about how things are built, not just that they work.
